Welcome

Welcome to my personal website. I created this website as a place to share information about myself, my academic interests, current projects, and other areas that are important to me. This site was developed using HTML, CSS, and JavaScript while applying principles of web design and user experience.

The goal of this website is to make information easy to find and understand. The navigation system allows visitors to move between the different pages of the website while maintaining a consistent layout. The design uses clear headings, readable text, contrasting colors, and organized sections to create a simple and effective user experience.

About This Website

The About Me page contains additional information about my background, education, interests, and goals. The Research page provides information about topics and projects that I am interested in exploring. The Contact page gives visitors a way to provide feedback or communicate with me through an embedded form.

I designed the website so that it can be viewed on both desktop and mobile devices. Responsive CSS allows the content to adjust when the screen becomes smaller. Navigation links also include hover effects so visitors receive visual feedback when interacting with different parts of the site.
